# 🎬 SDR To HDR Converter

![Version](https://img.shields.io/badge/version-2.5-blue.svg) ![Python](https://img.shields.io/badge/Python-3.10+-yellow.svg) ![Platform](https://img.shields.io/badge/Platform-Windows-0078D6.svg) ![License](https://img.shields.io/badge/license-MIT-green.svg)

SDR To HDR Converter 是一款专业的视频处理工具，专为将 SDR（标准动态范围）视频转换为 HDR（高动态范围）广播级标准而设计。

它基于 FFmpeg 和 NVIDIA NVEnc 硬件加速技术，实现色彩空间的精确映射（Rec.709 -> Rec.2020/P3），并支持 PQ 和 HLG 两种主流 HDR 标准。

## ✨ 核心功能 (Features)

### 🖥️ 图形化操作界面 (GUI)
- **现代化 UI**：基于 `CustomTkinter` 构建的暗色系界面，左右双栏布局（参数面板 + 运行日志）。
- **双模式运行**：
  - 📄 **单文件转换**：针对单个视频文件进行精细化处理。
  - 📂 **文件夹监控**：自动化监控指定目录，实现批量无人值守处理。
- **裁剪与切片**：独立标签页，支持按秒跳过片头/片尾，并按用户输入的每段时长自动切片输出。
- **预处理编辑器**：可视化时间线，支持标记入点/出点和删除片段。
- **实时状态栏**：底部三行状态显示（文件检测 / 预估大小 / 编码进度），窗口布局固定不抖动。

### ⚙️ 强大的视频编码控制
- **硬件加速**：完全利用 NVIDIA GPU (NVEncC) 进行编码。
- **编码格式**：支持 **HEVC/H.265 10bit** 和 **AV1 10bit**（需 RTX 40 系列及以上显卡）。
- **HDR 标准**：支持 **PQ (Perceptual Quantizer)** 和 **HLG (Hybrid Log-Gamma)**。
- **色彩空间**：支持 **Rec.2020** 和 **DCI-P3** 广色域。
- **跳过 HDR 转换**：HDR 模式下拉菜单中选择"SDR直通"，仅利用 GPU 编码进行裁剪/切片/转码，保持 SDR 输出。
- **专业参数**：
  - 分辨率、帧率 (FPS)、GOP 长度自定义。
  - **码率控制**：支持 CBR (固定码率) 和 VBR (动态码率)。
  - **编码等级**：开放 Profile (Main10), Level (5.0-6.2), Tier (Main/High) 设置。
  - **编码速度预设**：P1 (最快/质量低) 到 P7 (最慢/质量高)，或 default 自动选择。
- **GPU 缩放**：缩放由 NVEncC 的 GPU 侧执行（spline36），避免 FFmpeg CPU 缩放成为高分辨率处理瓶颈。
- **HEVC Level 自动匹配**：根据分辨率、帧率和码率自动计算并提升到合适的 HEVC Level，避免编码器报错。

### 📊 智能辅助模块
- **源文件信息展示**：选择文件后自动探测并显示视频编码、分辨率、帧率、音频格式、时长等完整媒体信息。
- **输出文件大小预估**：根据码率和时长实时估算输出文件大小，便于提前规划存储空间。
- **硬件检测**：自动探测 GPU 能力与 NVEncC 支持情况，并提供推荐编码参数。
- **智能诊断**：结构化错误分类系统，针对配置、硬件、媒体、进程等错误提供恢复建议。
- **预设管理**：支持预设的导入导出，具备完善的配置版本迁移机制（v1 -> v3）。
- **任务队列**：内置状态机驱动的任务管理，严格校验状态流转。

### 🎵 多音轨处理
- **多格式支持**：支持 AC3, AAC (libfdk_aac), MP2 等音频编码。
- **双音轨封装**：支持同时封装主音轨（如 5.1 声道）和副音轨（如立体声）。
- **立体声→5.1 上混**：2 声道到 5.1 声道使用 FFmpeg 滤镜，将立体声内容智能分配到前置、中置、LFE 和环绕声道，确保所有声道均有有效音频内容。
- **EBU R128 响度标准化**：可选的两遍式响度标准化处理，确保输出音频符合广播响度标准（目标 -24 LUFS）。

### ✂️ 裁剪与切片
- **片头/片尾裁剪**：按秒精确跳过片头和片尾（帧精确，非关键帧对齐）。
- **自动切片**：裁剪后按用户指定的每段时长自动分段输出，文件名追加 `_001`、`_002`、`_003` 后缀。
- **处理顺序**：先裁剪 → 再切片，确保逻辑清晰。

### 📦 输出格式
- **广播级 TS**：符合电视台播出标准的 MPEG-TS 封装。
- **网络级 MP4**：适合网络分发的高兼容性 MP4 封装（AV1 编码时自动切换为 MP4）。

### 🔄 断点续传
- **任务状态持久化**：编码过程中自动保存进度，中断后可从上次完成的分段继续。
- **配置一致性校验**：通过配置哈希确保续传时参数未被修改，避免输出不一致。
- **GUI 恢复提示**：启动任务时自动检测未完成的任务，弹窗询问是否继续。

### 🖥️ 多 GPU 并行
- **自动 GPU 检测**：启动时自动探测系统中所有 NVIDIA GPU。
- **并行分段编码**：多显卡环境下，不同分段自动分配到不同 GPU 并行编码，大幅缩短处理时间。
- **一键开关**：GUI 中勾选即可启用，单 GPU 时自动禁用。

## 🛠️ 环境依赖 (Requirements)

本软件依赖以下组件运行：

1.  **操作系统**: Windows 10/11 (64位)
2.  **硬件**: NVIDIA 显卡（HEVC 编码需支持 NVENC；AV1 编码需 RTX 40 系列及以上）

## ⚠️ 已知限制 (Known Limitations)

- **系统平台**: 仅支持 Windows 系统。
- **硬件依赖**: 核心编码功能依赖 NVIDIA GPU (NVEnc)。若无显卡，系统将根据硬件探测结果建议切换至 FFmpeg 软件编码（速度较慢）。
- **AV1 编码**: 需要 RTX 40 系列及以上显卡，且仅支持 MP4 输出（不支持 TS 封装）。
- **预览功能**: 暂不支持转换过程中的实时画面预览。
- **多 GPU**: 并行编码仅在分段模式下生效，单段文件无法并行。

## 🚀 快速开始 (Quick Start)

### 1. 运行软件
双击 `SDR To HDR Converter V2.5.exe` 启动程序。

### 2. 参数设置
- **源文件**: 点击"导入视频"选择 SDR 素材。
- **HDR 模式**: 根据需求选择 `PQ` 或 `HLG`（或勾选"跳过 HDR 转换"仅做裁剪/转码）。
- **视频参数**: 推荐使用默认的 `Main10` Profile 和 `5.1` Level。
- **裁剪设置**: 如需跳过片头/片尾，在输出选项卡填入秒数；如需切片，填入每段时长。
- **音频设置**: 根据源文件声道情况配置音轨 1 和音轨 2。

### 3. 开始转换
点击底部的 **🚀 开始任务** 按钮。
- 程序会自动调用 FFmpeg 进行色彩映射（或直通），并传输给 NVEncC 进行编码。
- 进度条和日志窗口会实时显示处理进度。
